# Website Traffic Analysis Dashboard

## Overview

This project analyzes website traffic and user engagement using Power BI.

The dashboard provides insights into website users, sessions, bounce rate, traffic sources, session duration, page performance, conversion rates, and goal completions.

## Objectives

- Analyze website traffic and user activity
- Identify major traffic sources
- Evaluate user engagement
- Analyze session duration and pages per session
- Compare page conversion rates
- Identify high and low performing pages
- Track goal completions
- Create an interactive Power BI dashboard

## Key Metrics

- Total Users
- Total Sessions
- Bounce Rate
- Average Session Duration
- Pages per Session
- Average Conversion Rate
- Total Event Count
- Total Goal Completions

## Dashboard Pages

### Page 1 – Website Traffic Overview

Provides an overall summary of website traffic, including users, sessions, bounce rate, pages per session, and traffic sources.

### Page 2 – Traffic Sources and Engagement

Analyzes traffic sources such as Organic, Direct, Referral, Paid, and Social, along with engagement rate and session duration.

### Page 3 – Conversion and Page Performance

Analyzes conversion rates, goal completions, page performance, users, sessions, and bounce rates for individual pages.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis


## Insights

- Organic traffic is the largest traffic source.
- Different traffic sources show different engagement and session-duration patterns.
- Website pages have different conversion rates and goal completions.
- Page-level analysis helps identify high and low performing pages.
